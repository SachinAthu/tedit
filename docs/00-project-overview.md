# Terminal Text Editor — Project Overview

## Purpose

This repository contains the implementation of a small, professional-quality, terminal-based text editor called Tedit written in C.

The project is developed as a real application with incremental implementation, testing, debugging, and refinement.

The goal is to build a maintainable editor rather than a tutorial prototype or a collection of disconnected examples.

---

## Technology

- **Language:** C99
- **Primary platform:** Linux/POSIX
- **Build system:** CMake
- **Terminal:** POSIX terminal facilities and ANSI-compatible terminal output
- **Version control:** Git
- **Testing:** Automated unit, integration, and end-to-end tests

The implementation should keep platform-specific code isolated so that future portability is possible.
