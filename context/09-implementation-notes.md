# Implementation Notes

## Initial Notes

- Volume X implements the architecture established in Volumes I–IX.
- The implementation is developed in a separate repository from the book.
- C99 and Linux/POSIX are the primary implementation targets.
- CMake is the build system.
- Development and Release builds are maintained separately.
- Tests are integrated into the build system.
- Implementation proceeds in small, verified units.
- Architectural changes must be recorded rather than silently introduced through code.
- Git commits should represent focused engineering changes.
